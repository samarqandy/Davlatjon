# Проверки чертежа «Shaxmat shohnomasi»

Скрипты, которыми проверены позиции, линии и подсчёты в `docs/shohnoma/BLUEPRINT.md` (chess.js, только чтение).
Запуск из корня репозитория: `node scripts/shohnoma/<файл>.cjs`. `final_checks.cjs` перебирает мат в четыре хода —
около двух минут. В сборку сайта и в тесты не входят: когда главы книги станут данными, эти проверки заменит
`tests/book.test.ts` (раздел 9 чертежа).
