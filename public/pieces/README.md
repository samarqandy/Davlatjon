# Наборы фигур

Файлы взяты без изменений из открытых наборов; лицензии разрешают использование, в том числе коммерческое,
с сохранением текста лицензии и имени автора. Источник копий — репозиторий lichess-org/lila, папка `public/piece`
(лицензии сверены по его файлу `COPYING.md` 12.11.2026).

| Папка      | Автор           | Лицензия   | Оригинал                                    |
| ---------- | --------------- | ---------- | ------------------------------------------- |
| `celtic`   | Maurizio Monge  | MIT        | https://github.com/maurimo/chess-art        |
| `chessnut` | Alexis Luengas  | Apache 2.0 | https://github.com/LexLuengas/chessnut-pieces |

Текст лицензии лежит в каждой папке (`LICENSE.txt`). Наборы под GPL, AGPL и «некоммерческие» (CC BY-NC-SA)
не берём: первые требуют открыть код сайта, вторые не подходят учебному центру.

Новый набор: 12 файлов `wK … bP` в формате SVG без скриптов и внешних ссылок, `LICENSE.txt`, строка в этой таблице
и запись в `PIECE_SETS` (`src/lib/boardLook.ts`). Проверяет `tests/board-look.test.ts`.
