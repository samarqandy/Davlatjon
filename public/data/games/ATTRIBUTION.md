# Партии для доски тренера — источники и лицензии

Файлы в этой папке собирает `scripts/games/build-games.mjs` (список источников — `scripts/games/sources.json`).
Из источников взяты только сведения о партиях: игроки, рейтинги, турнир, город, дата, тур, результат и ходы.
Изменения: ходы проверены и переписаны в запись UCI; имена игроков приведены к одному написанию; оценки движка,
время на часах, комментарии и пометки источников удалены; добавлены посчитанные программой семейство дебюта и код
ECO (по открытому списку дебютов Lichess, CC0) и полуход, с которого партия перешла в эндшпиль. Наши подписи,
разделы и заметки в эти файлы не входят.

## broadcasts.cc-by-sa-4.0.json — 759 партий

Партии из трансляций Lichess (lichess.org/broadcast); трансляции Lichess распространяются по лицензии CC BY-SA 4.0 (database.lichess.org).
Лицензия: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Источник: https://lichess.org/broadcast
У каждой партии в поле `src` — ссылка на неё в трансляции. Этот файл распространяется на тех же условиях
(CC BY-SA 4.0).

## wikimedia.cc-by-sa-4.0.json — 157 партий

Ходы партий — из статей Википедии и страниц Викисклада (авторы — участники Викимедиа; правки указаны у каждой партии). Часть партий — по набору «Famous games and championship classics» проекта Kingfisher (github.com/mardakurt/kingfisher, CC BY-SA 4.0).
Лицензия: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Источник: https://en.wikipedia.org/wiki/List_of_chess_games
У каждой партии в поле `src` — правка статьи или страницы файла, откуда взяты ходы. Этот файл распространяется
на тех же условиях (CC BY-SA 4.0).

## public-domain.json — 14 партий

Партии из книги Х. Р. Капабланки «Chess Fundamentals» (1921).
Общественное достояние: книга издана в 1921 году, автор умер в 1942 году. Ходы сверены с текстом книги
(Project Gutenberg, электронная книга №33870) по расшифровке github.com/mardakurt/kingfisher (MIT).
