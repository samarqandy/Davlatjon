# Шахматы по сети (друзья, партии, переписка)

Раздел `/chess/online`. Работает, когда на сайте настроены **вход через Google или Telegram** и **база Neon**
(те же переменные, что для синхронизации прогресса — см. `login-setup.md`). Отдельных сервисов не нужно:
ходы доходят опросом сервера раз в 1,5 секунды, таблицы создаются сами при первом обращении.

## Как это устроено

| Что                                                                             | Где                                                                                 |
| ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Правила партии, часы, итоги, имена, проверка сообщений                          | `src/lib/online.ts` (чистая логика, без базы)                                       |
| Таблицы `lab_profiles`, `lab_friends`, `lab_games`, `lab_messages`, `lab_reads` | `src/lib/server/playStore.ts`                                                       |
| Запросы браузера                                                                | `src/app/api/play/*` — `me`, `search`, `friends`, `games`, `game`, `messages`       |
| Экран друзей и партий                                                           | `src/components/online/OnlineHub.tsx`, `OnlineGame.tsx`, `FriendChat.tsx`           |
| Выключатели родителя                                                            | `src/components/parent/OnlineControls.tsx` (раздел «Настройки» → «Шахматы по сети») |

- Игрок — это аккаунт (Google или Telegram). Имя в игре (`a–z`, цифры, `_`, 3–16 знаков) он выбирает сам; настоящие
  имена из Google или Telegram другим игрокам **не показываются**.
- Каждый ход проверяет сервер. Время хранится как «остаток на момент последнего хода», поэтому игрок, закрывший
  вкладку, не может остановить часы соперника: сервер сам фиксирует «время вышло» при ближайшем запросе. Первые два
  хода (по одному у каждого) идут без часов.
- Игроки играют только с теми, кто у них в друзьях. Просьба о дружбе уходит по имени; встречная просьба сразу делает
  друзьями. Можно убрать из друзей и заблокировать.
- Приглашение, на которое не ответили неделю, пропадает. Одновременно можно держать до 6 открытых партий, до 50 друзей.

## Безопасность детей

- Переписка — только между друзьями, до 200 знаков, не чаще 15 сообщений в минуту.
- Не отправляются: ссылки и названия сайтов, упоминания мессенджеров, номера телефонов, почта и грубые слова
  (русские, узбекские, английские; список — `BAD_WORDS` в `online.ts`). Это защита от самого очевидного, а не
  замена присмотру: поэтому у родителя есть выключатели.
- Родитель в настройках включает и выключает **игру по сети**, **переписку** и **поиск по имени**
  («меня можно найти»). Выключено — человека не находят в поиске и ему нельзя написать.
- Случайных соперников нет: никакого «найти любого игрока».

## Проверка

- `npm test` — `tests/online.test.ts` (правила и часы), `tests/play-store.test.ts` и `tests/play-api.test.ts`
  (настоящий Postgres в памяти — PGlite, тот же SQL, что на Neon).
- `npx playwright test e2e/online.spec.ts` — два браузера и один «сервер» в памяти: имя → поиск → дружба → партия → ход →
  переписка → сдача.

## Что ещё можно добавить

Жалоба на игрока, уведомления о ходе, запись сыгранных партий в разбор и медали, поиск соперника по уровню.
