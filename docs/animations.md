# Анимации и геймификация: птица Парвоз, опыт, салют

Всё работает **без** файлов Rive и Lottie: пока их нет, интерфейс рисует запасной вариант
(логотип `logo.webp` + CSS-движения, конфетти из CSS). Когда файлы появятся, их включают одним флагом.

## Где что лежит

| Файл                                        | Зачем                                                                                     |
| ------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `src/lib/anim/assets.ts`                    | Реестр файлов анимации (`available: true/false`), адреса WASM-движков.                    |
| `src/lib/anim/mood.ts`                      | Шесть настроений птицы и перевод в команды Rive (`riveCommand`).                          |
| `src/lib/anim/confetti.ts`                  | Детерминированные кусочки конфетти (чистая функция, без случайности в рендере).           |
| `src/lib/motion.ts`, `src/lib/useMotion.ts` | Можно ли анимировать: система (`prefers-reduced-motion`) + настройка родителя «Анимации». |
| `src/components/mascot/MascotLive.tsx`      | Птица с настроением: запасная CSS-версия или Rive.                                        |
| `src/components/mascot/MascotRive.tsx`      | Rive-птица (грузится лениво, только если файл есть).                                      |
| `src/components/rewards/Confetti.tsx`       | Салют на весь экран (CSS или Lottie).                                                     |
| `src/components/rewards/LottieBurst.tsx`    | Lottie-салют (лениво).                                                                    |
| `src/components/progress/XpToast.tsx`       | «+N XP ⭐» взлетает; новый уровень — птица-праздник и салют.                              |
| `src/components/answers/Feedback.tsx`       | Птица реагирует на верный/неверный ответ — во всех ~70 местах сразу.                      |
| `scripts/copy-anim-wasm.mjs`                | После `npm install` копирует WASM-движки в `public/vendor/` (в git не хранятся).          |

## Настроения птицы

`idle` (покой), `happy`, `thinking`, `correct` (разово), `incorrect` (разово), `celebration`.

- `correct` — верный ответ; `incorrect` — мягкое «подумаем ещё»: птица наклоняет голову, **без тряски, слёз и слова «неправильно»**.
- `celebration` — конец дня, хороший результат «Быстрых примеров», новый уровень.
- Птица на экране отдыха (`RestStop`) остаётся спокойной: там нет наград и счёта.

## Как заменить запасной вариант файлом Rive

1. В редакторе Rive нарисуйте птицу по `public/logo.webp` (тот же силуэт, цвета, шапочка с кисточкой, эмблема на крыле).
2. Договорённость об именах (регистр важен):
   - файл `public/animations/mascot.riv`, артборд `Parvoz`, state machine `Mascot`;
   - вход Number `mood`: 0 покой, 1 радость, 2 раздумье, 5 праздник (3 и 4 допустимы: разовая реакция и возврат в покой);
   - входы Trigger `correct` и `incorrect` — разовые реакции (после них птица сама возвращается в покой);
   - не использовать Rive Text, Layouts, Scripting и Audio: подключён лёгкий рантайм `@rive-app/react-canvas-lite`.
3. Положите файл в `public/animations/` и поставьте `available: true` у `mascot` в `src/lib/anim/assets.ts`.
4. `tests/anim-assets.test.ts` проверит, что флаг совпадает с файлом. Если файл не загрузится, птица сама вернётся к запасной.

Салют из Lottie: `public/animations/confetti.lottie` и `available: true` у `confetti`.

## Библиотеки и лицензии

- `@rive-app/react-canvas-lite` 4.36.0 (рантайм `@rive-app/canvas-lite` 2.44.0) — MIT. Только для птицы.
- `@lottiefiles/dotlottie-react` 0.20.0 (`dotlottie-web` 0.81.0) — MIT. Только для разовых эффектов-наград.
- Версии зафиксированы без `^`: WASM-движок должен совпадать с версией пакета (проверяет тест).
- Оба WASM отдаются с нашего домена (`/vendor/…?v=версия`, `Cache-Control: immutable`, офлайн через service worker),
  а не с unpkg/jsDelivr: для детского сайта лишние сторонние запросы недопустимы.
- Лицензия кода (MIT) не распространяется на сами файлы `.riv`/`.lottie`: берите только свои или с явной разрешающей лицензией.
- Библиотеки грузятся лениво (`next/dynamic`, `ssr: false`) и только когда файл действительно есть, поэтому сейчас в первую загрузку не попадают.

## «Уменьшить движение» и настройки

CSS-правило в `globals.css` останавливает только CSS. Rive, Lottie и конфетти работают через JS, поэтому
`useMotionAllowed()` проверяет `prefers-reduced-motion` сам и настройку родителя («Настройки → Анимации»,
по умолчанию включено; настройка устройства, между устройствами не синхронизируется).
Когда анимации выключены: птица неподвижна, салюта и Rive/Lottie нет, награда («+XP», «Новый уровень») остаётся текстом.

## Мобильные

Конфетти — только `transform`/`opacity`, на узком экране показывается каждый второй кусочек, слой `fixed inset-0
overflow-hidden pointer-events-none` (полос прокрутки нет, касаниям не мешает), ниже всплывающих наград.
Lottie ограничен `devicePixelRatio ≤ 2` и замирает вне экрана; Rive ставится на паузу вне экрана
(`shouldUseIntersectionObserver`).
