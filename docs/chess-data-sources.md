# Открытые источники шахматных партий: что можно брать

Проверено 14.11.2026 по первоисточникам (страницы лицензий, условия сайтов, файлы лицензий в репозиториях) для базы партий
доски тренера (MENTOR-3) и для списка источников, предложенного владельцу другим помощником. Это не юридическое
заключение; перед платной версией — проверка у юриста. Правила проекта: только явная свободная лицензия (CC0, общественное
достояние, MIT/Apache/BSD; CC BY-SA — только отдельным файлом с указанием авторства), код и вид Lichess не берём, код под
GPL/AGPL в сборку сайта не попадает.
