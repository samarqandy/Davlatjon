# Как писать по-узбекски в Лаборатории Давлатжона

Узбекская версия — не подстрочник русской. Каждый текст пишем заново так, как его сказал бы
живой узбекский учитель восьми–одиннадцатилетнему ребёнку: коротко, тепло, естественно.
Смысл, числа, ответы и шахматные ходы — те же, что в русском оригинале; слова и порядок фраз — свои.

## 1. Орфография

- Только латиница (1995). **Ни одной кириллической буквы** — это проверяют тесты.
- `oʻ`, `gʻ` пишем с **ʻ** (U+02BB): oʻyin, toʻgʻri, gʻalaba, Oʻzbekiston, Ulugʻbek.
- Знак _tutuq belgisi_ — **ʼ** (U+02BC): maʼlum, taʼlim, sanʼat, sheʼr, maʼno, eʼtibor, taʼsir, jurʼat, qatʼiy.
- Не использовать вместо них `'`, `‘`, `’`, `` ` ``.
- Внимательно с парами букв: **x** (xat, xato, oxir) и **h** (hovli, hisob, hamma); **q** (qator, qizil) и **k** (katak, koʻp);
  **ng** (ming, keng); **sh**, **ch**.
- Порядковые числа — через дефис: 3-kun, 2-hafta, 5-masala, 1-oʻrin, 2021-yil, 1497-yilda.
  Века — римскими цифрами: XV asr, VI asrda.
- Падежные окончания после чисел и клеток доски пишем **отдельно**, как в узбекских учебниках:
  «12 ni 3 ga boʻl», «e4 ga yur», «f3 dagi ot», «g7 ni himoya qiladi».
- Кавычки «ёлочки», тире « — », как в русском тексте. Разметка `**жирный**` и `` `пример` `` сохраняется.

## 2. К кому обращаемся

- **Ребёнку — «sen»**: «Salom, Davlatjon!», «Qani, oʻylab koʻr», «Topdingmi?», «Barakalla!».
- **Родителю — «siz»**: «Farzandingiz…», «Unga … deb soʻrang», «Eʼtibor bering».
- Повелительное наклонение для ребёнка мягкое: «hisoblab koʻr», «sinab koʻr», «tekshirib koʻr» — вместо сухого «hisobla» там, где русский текст мягкий.

## 3. Живой язык, а не перевод

Плохо (калька) → хорошо (по-узбекски):

| Русский              | Не так                            | А так                                |
| -------------------- | --------------------------------- | ------------------------------------ |
| Молодец!             | Yaxshi bola!                      | Barakalla! / Ofarin! / Zoʻr!         |
| Не торопись          | Tezlashma                         | Shoshilma                            |
| Попробуй ещё раз     | Yana bir marta harakat qilib koʻr | Yana urinib koʻr                     |
| Обрати внимание      | Diqqatingni qarat                 | Eʼtibor ber                          |
| Подумай хорошенько   | Yaxshilab oʻyla                   | Yaxshilab oʻylab koʻr                |
| Что известно?        | Nima maʼlum boʻlgan?              | Nima maʼlum?                         |
| Застрял?             | Qotib qoldingmi?                  | Qiynaldingmi?                        |
| Неверно              | Notoʻgʻri javob berildi           | Hali toʻgʻri emas — yana oʻylab koʻr |
| Задача со звёздочкой | Yulduzchali zadacha               | Yulduzchali masala                   |
| Давай разберёмся     | Keling, tahlil qilamiz            | Qani, birga koʻrib chiqamiz          |
| Интересно, правда?   | Qiziq, toʻgʻrimi?                 | Qiziq-a?                             |

- Короткие предложения. Один абзац — одна мысль.
- Не нанизывать отглагольные существительные («amalga oshirilishi zarur boʻlgan…»).
- Не тащить русский порядок слов: сказуемое — в конце.
- Русские слова, у которых есть обычное узбекское: не «zadacha», а **masala**; не «otvet», а **javob**.
- Устойчивые обороты по-узбекски: «bosh qotirmoq», «koʻz yugurtirmoq», «qoyil qolmoq», «ish oson emas», «bir qarashda».
- Юмор и интонация — по-узбекски, а не переведённые русские шутки.

## 4. Имена и названия

- Обычные детские имена из задач: Бобур → **Bobur**, Тимур → **Temur**, Дима → **Diyor**, Катя → **Kamola**, Маша → **Malika**,
  Петя → **Bekzod**, Коля → **Aziz**, Саша → **Sardor**, Оля → **Oydin**. Внутри одной задачи имя меняем везде
  (условие, варианты, подсказки, ответ, решение).
- Давлатжон → **Davlatjon**.
- Исторические лица Востока — в узбекской традиции: Ибн Сина → **Ibn Sino**, Беруни → **Abu Rayhon Beruniy**,
  аль-Хорезми → **Muhammad al-Xorazmiy**, Улугбек → **Mirzo Ulugʻbek**, Тимур (эмир) → **Amir Temur**,
  Омар Хайям → **Umar Xayyom**, Навои → **Alisher Navoiy**, Фирдоуси → **Firdavsiy**, «Шахнаме» → **«Shohnoma»**,
  ас-Сули → **as-Suliy**, аль-Адли → **al-Adliy**, аль-Мамун → **al-Maʼmun**, Дилярам → **Dilorom**.
- Места: Бухара → **Buxoro**, Самарканд → **Samarqand**, Хорезм → **Xorazm**, Хива → **Xiva**, Ташкент → **Toshkent**,
  Багдад → **Bagʻdod**, Афрасиаб → **Afrosiyob**, Индия → **Hindiston**, Персия → **Eron** (или Fors), Испания → **Ispaniya**.
- Европейские имена — по произношению, узбекской латиницей: Эйлер → **Eyler**, Филидор → **Filidor**, Морфи → **Morfi**,
  Каспаров → **Kasparov**, Карлсен → **Karlsen**, Алехин → **Alyoxin**, Капабланка → **Kapablanka**, Стейниц → **Steynits**,
  Кемпелен → **Kempelen**, Абдусатторов → **Nodirbek Abdusattorov**, Касымджанов → **Rustam Qosimjonov**.
- Монеты в задачах — **tanga**. Числа не меняем никогда.

Запись ходов — **фигурками**: ♔ король, ♕ ферзь, ♖ ладья, ♗ слон, ♘ конь; пешка — без значка.
Русская запись переводится так: «Кр» → ♔, «Ф» → ♕, «Л» → ♖, «С» → ♗, «К» → ♘ («Фxf7#» → «♕xf7#», «1. Кf3 Кc6» → «1. ♘f3 ♘c6»).
Рокировка — «0-0» и «0-0-0». Координаты клеток (a1…h8) не меняются.

## 6. Математика

| Русский                                   | По-узбекски                                                   |
| ----------------------------------------- | ------------------------------------------------------------- |
| задача / пример / ответ / решение         | masala / misol / javob / yechim                               |
| сложить, вычесть, умножить, разделить     | qoʻshmoq, ayirmoq, koʻpaytirmoq, boʻlmoq                      |
| сумма, разность, произведение, частное    | yigʻindi, ayirma, koʻpaytma, boʻlinma                         |
| число, цифра, чётное, нечётное            | son, raqam, juft, toq                                         |
| закономерность, правило, ряд              | qonuniyat, qoida, qator (ketma-ketlik)                        |
| клетка, таблица, строка, столбец          | katak, jadval, qator, ustun                                   |
| квадрат, прямоугольник, треугольник, круг | kvadrat, toʻgʻri toʻrtburchak, uchburchak, doira              |
| проверить, доказать, перебрать варианты   | tekshirmoq, isbotlamoq, variantlarni birma-bir koʻrib chiqmoq |
| гипотеза, догадка                         | faraz, taxmin                                                 |
| в 2 раза больше                           | 2 marta koʻp                                                  |

После числа существительное не во множественном числе: «5 ta olma», «3 kun», «7 ta masala».
Со счётными предметами уместно «ta»; с единицами измерения — без него: «5 kilogramm», «3 soat».

## 7. Что не переводить

id, FEN, ходы вида «e2e4», ссылки (`href`), id картинок, названия цветов в коде (`"red"`), значения вроде `"warmup"`,
классы CSS. Только то, что читает человек. Комментарии в коде остаются русскими.

## 8. Задачи с ответами

- Если ответ — слово или вариант, переводим **согласованно**: вариант ответа, сам ответ, подсказки и решение.
- Клетки карт с русскими буквами (А, Б, В…) → латинские **A, B, C, D, E, F…** по порядку — везде в задаче, включая ответ.
- Шифры и таблицы «буква — номер» собираем заново на латинском алфавите `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
  (без oʻ, gʻ и сочетаний sh/ch в шифруемых словах) и пересчитываем ответ.
- Ребёнок набирает oʻ как угодно (o', o‘, oʻ) — проверка ответа это понимает.
