# Турниры: жеребьёвка и таблица

Раздел `/chess/tournaments` — инструмент организатора (учитель, тренер, родитель): составить пары, записать результаты, получить таблицу. Турнир проходит за настоящими досками; сайт ведёт только протокол.

Это не сертифицированная ФИДЕ программа. Для турнира с обсчётом рейтинга ФИДЕ нужна программа из её официального списка — об этом сказано и на самой странице.

## 1. Что смотрели

Разбор 12.11.2026 (поиск — Tavily, правила — по Справочнику ФИДЕ).

| Платформа                          | Что берём                                                                                                      | Что не берём                                                        |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Swiss-Manager и chess-results.com  | набор систем (круговая, швейцарская, на выбывание), дополнительные показатели по порядку, перекрёстная таблица | установка на компьютер, сотни настроек                              |
| Lichess (швейцарские турниры)      | жеребьёвка по голландской системе, вступление опоздавшего, выбывание без удаления из таблицы                   | игра по сети со случайными соперниками (правило безопасности детей) |
| ChessManager, Chess Caddy, chess67 | ввод результата одним нажатием на телефоне, список участников вставкой текста                                  | регистрация участников, оплаты, публикация в сети                   |

Отсюда рамка: телефон в руке организатора, результат — одно нажатие, без аккаунта и без сервера.

## 2. Системы

| Система     | Участников | Туров                                                                             | Жеребьёвка                      |
| ----------- | ---------- | --------------------------------------------------------------------------------- | ------------------------------- |
| Круговая    | 3–24       | n − 1 (при нечётном n — n)                                                        | таблицы Бергера                 |
| В два круга | 3–12       | вдвое больше                                                                      | второй круг — с переменой цвета |
| Швейцарская | 4–150      | предлагается ⌈log₂ n⌉ (не меньше 3; +1, если участников больше 8), можно изменить | по очкам, тур за туром          |
| Олимпийская | 2–64       | до победителя                                                                     | сетка по стартовым номерам      |

Стартовые номера раздаются жребием, по рейтингу или как в списке. Список участников — по одному в строке; число из трёх-четырёх цифр в конце строки читается как рейтинг («Али 1200»).

### Круговая (`src/lib/tournament/roundRobin.ts`)

Расписание — таблицы Бергера (Справочник ФИДЕ, C.05, приложение 1). Тест сверяет таблицы для 4, 6, 8, 10, 12 и 16 участников с текстом справочника дословно. При нечётном числе участников один в каждом туре свободен от игры и очков за это не получает. В двух кругах два последних тура первого круга меняются местами (рекомендация того же приложения: иначе кто-то играет одним цветом три раза подряд).

### Швейцарская (`src/lib/tournament/swiss.ts`)

Основные правила (C.04.1) соблюдаются всегда, пока это возможно:

- двое не играют друг с другом дважды;
- свободным от игры участник бывает один раз и получает очко;
- никто не играет одним цветом три раза подряд, разница «белые − чёрные» не выходит за ±2.

Порядок пар — как в голландской системе (C.04.3): участники с равными очками делятся пополам, верхняя половина играет с нижней; кому пары не хватило, спускается к следующей группе. Цвет — по предпочтениям (статьи 5.2.1–5.2.5).

Тупиков внутри тура нет: перед тем как поставить пару, программа проверяет наибольшим паросочетанием (`matching.ts`, алгоритм Эдмондса), что остальных ещё можно разбить на пары. Если все правила соблюсти нельзя, они ослабляются по порядку — сначала цвет, потом повторный свободный тур — и над туром появляется пометка. Повторная встреча не допускается никогда: если без неё пар не составить, турнир честно говорит, что следующего тура не будет.

Участник может выбыть (пару больше не получает, в таблице остаётся) и вернуться; опоздавший вступает со следующего тура.

**Чего нет по сравнению с полной голландской системой:** полного перебора критериев качества пар (история «спусков» между группами, особые правила для лидеров последнего тура), полуочковых пропусков по заявке, ускоренной жеребьёвки, ручной правки пар.

### Олимпийская (`src/lib/tournament/knockout.ts`)

Сетка по стартовым номерам: первый и второй номера встречаются только в финале; если участников не степень двойки, сильнейшие свободны в первом туре. Ничьей нет — организатор записывает победителя пары (после переигровки или по жребию). Матч за третье место включается галочкой.

## 3. Таблица (`src/lib/tournament/standings.ts`)

Дополнительные показатели — по C.07 (редакция с 1 марта 2026 года):

- **швейцарская:** очки → Бухгольц без худшего результата → Бухгольц → Зоннеборн-Бергер → число побед;
- **круговая:** очки → личные встречи → Зоннеборн-Бергер → число побед.

Несыгранные туры считаются по статье 16: свободный тур, неявка и пропуск не дают настоящего соперника, поэтому в показателях стоит условный соперник (16.4), а для чужих показателей очки участника поправляются (16.3). Равные по всем показателям делят место. Неявка записывается отдельным результатом («+/−»).

## 4. Хранение и личные данные

- Турниры лежат в браузере организатора (`localStorage`, ключ `davlatjon-lab:tournaments:v1`), отдельно от прогресса ребёнка. В аккаунт и на сервер они не уходят: имена участников — чужие личные данные.
- Перенос на другое устройство — файлом (кнопка «Сохранить в файл» и загрузка на странице списка). Файл проверяется целиком (`parseTournament`): лишнее отбрасывается, неполное не принимается.
- Хранится не больше 50 турниров; самые старые уходят.
- Таблицу и пары можно напечатать.

## 5. Проверка

- `tests/tournament.test.ts` — таблицы Бергера по справочнику; свойства круговой (каждый с каждым один раз, цвета); паросочетание против полного перебора; швейцарская на случайных турнирах (13 размеров × 3 набора результатов): нет повторных встреч, свободный тур — один раз, цвета в пределах правил; 150 участников; олимпийская; показатели таблицы.
- `e2e/tournament.spec.ts` — три системы от создания до итогов на телефоне и компьютере, файл, удаление, узбекский интерфейс без кириллицы.
- Страница есть в списках `e2e/a11y.spec.ts` и `e2e/no-hscroll.spec.ts`.

## 6. Что дальше (не сделано)

- Командные турниры и турниры по сети — нет. Игра по сети остаётся только с друзьями.
- Выгрузка в формате TRF (для проверки пар внешней программой и подачи на рейтинг) — нет.
- Ручная правка пар и полуочковые пропуски по заявке — нет.
- Общая ссылка «таблица для родителей» требует сервера и согласия на публикацию имён — решение владельца.
